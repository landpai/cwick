接入方式

这个页面只访问本机同源接口。下面这个地址是给外部客户端连本机 cwick 用的：

http://127.0.0.1:8000/v1

curl 示例（chat/completions）

curl http://127.0.0.1:8000/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"glm-5.3-flash","messages":[{"role":"user","content":"你好"}]}'

同一台服务也答 Responses 协议（Codex 等客户端用这个）

curl http://127.0.0.1:8000/v1/responses \
  -H 'Content-Type: application/json' \
  -d '{"model":"glm-5.3-flash","input":"你好","stream":true}'

以及 Anthropic 的 Messages 协议（Claude Code 用这个）

curl http://127.0.0.1:8000/v1/messages \
  -H 'Content-Type: application/json' \
  -d '{"model":"glm-5.3-flash","max_tokens":128,"stream":true,
       "messages":[{"role":"user","content":"你好"}]}'
